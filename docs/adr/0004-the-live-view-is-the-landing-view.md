# The Live view is the landing view

Users open the dashboard during games to follow a contest, so a separate Latest overview page was an extra click every time. The authenticated home is now the Live view, and the Latest page is retired; per-sport freshness moved into the sport tabs. "Latest" still names the most recent snapshot. The multi-contest Sport page is kept under "All contests" because it is the only view of non-primary contests.

**Update:** the sport the home page opens is now chosen live first, then the sport whose primary contest completed most recently, then the last-viewed sport, then the first sport. Last-viewed no longer wins outright, because the morning after a contest it hid the Final standings. The Live view is still the landing view.
