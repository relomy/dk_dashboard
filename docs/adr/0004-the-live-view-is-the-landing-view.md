# The Live view is the landing view

Users open the dashboard during games to follow a contest, so a separate Latest overview page was an extra click every time. The authenticated home is now the Live view for the last sport viewed (falling back to the first sport with a live primary contest), and the Latest page is retired; per-sport freshness moved into the sport tabs. "Latest" still names the most recent snapshot. The multi-contest Sport page is kept under "All contests" because it is the only view of non-primary contests.
